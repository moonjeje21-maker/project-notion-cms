# 검색 엔진 색인 거부(F012) 제거 계획

날짜: 2026-10-09 · 프로젝트: project-notion-cms

## 배경 (Context)

- 기획 문서 v4와 PRD는 "로그인 없이 주소를 아는 사람만 보되, 검색 엔진 색인은 거부한다"고 정했고, PRD는 이를 기능 **F012**(루트 `app/layout.tsx`의 `metadata.robots`)로 적어 두었다.
- 사용자 결정 (2026-10-09): **검색 엔진 색인을 거부하지 않는다.** 색인을 허용하면 따로 만들 기능이 없으므로(Next.js 기본값이 색인 허용) F012를 삭제한다.
- 코드에는 아직 `robots` 설정이 없다 (`grep -rn robots src/` 결과 없음). 고칠 것은 문서 3개다.
- 기록 성격의 파일은 건드리지 않는다: `docs/prd/*-validation.md`, `plans/*-fix-plan.md`, `plans/*-prd-agents-update-plan.md`, `plans/*-claude-md-update-plan.md`, `plans/*-prd-regenerate-plan.md`. 이 파일들에 남은 F012·noindex 언급은 당시 상태의 기록이다.

### 4. 계획 파일

## 범위 밖 (이번에 하지 않음)

- 검색에 잘 보이게 하는 작업(페이지 `title`·`description` 메타, `sitemap`, Open Graph)은 색인 허용의 자연스러운 다음 단계지만 요청에 없으므로 넣지 않는다. 원하면 별도 계획으로
- 코드 변경 없음 (아직 `robots` 설정이 없다)

grep -o "F0[0-9][0-9]" docs/prd/2026-10-09-project-notion-cms-prd.md | sort -u         # F001~F004, F010, F011 (6개)
grep -c '^```' docs/prd/2026-10-09-project-notion-cms-prd.md                           # 4
grep -n "색인\|robots" plans/2026-10-09-project-notion-cms-interior-service-plan.md CLAUDE.md  # 기획 15행·109행(허용)만, CLAUDE.md는 없음
